What does a forecast mean?

A forecast is an estimate based on patterns in past readings. It is not a guarantee of what will happen.

1
Recent readings

The model looks at recent glucose values and, if available, other validated inputs.

2
Estimated future

The model produces an estimate for a specified time horizon.

3
Uncertainty range

A calibrated range communicates that the estimate may be wrong. The method and test coverage should be documented.

Checks we will run

These checks help flag data that may make a forecast unreliable.

Reading checks

✓
Duplicate timestamps

Find multiple readings with the same participant and time.

✓
Missing readings and long gaps

Do not treat rows separated by large gaps as evenly spaced samples.

✓
Unexpected values

Flag suspicious records for review rather than silently changing them.

Before showing a forecast

GlucoBloom should check that recent readings are sufficient, timestamps are valid, and the model is available. If not, explain why no forecast is shown.

Planned safe behavior

“We can't show a reliable forecast right now because some recent readings are missing. Check the data connection and try again.”
